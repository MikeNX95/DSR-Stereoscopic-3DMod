# Dead Space (2023 Remake) — Stereoscopic 3D (AFR) 

### 📦 Installation
1. Download **Ultimate ASI Loader** ( `dinput8.dll` or `dxgi.dll` or `version.dll` ):
   https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases
3. Place `DS23-3D-6DOF.asi` and `3D-6DOF config.ini` into your game directory right next to `game.exe`.

The Stereo Output setting can be in the 3D-6DOF config.ini
